# PDF to DWG 转换工具 - 产品需求书

## 1. 项目概述

### 1.1 项目名称
PDF/图片转 DWG 在线工具

### 1.2 项目目标
提供一个在线工具，让用户上传 PDF 或图片文件，自动提取其中的线条和轮廓，生成可编辑的 DWG 文件供下载。

### 1.3 目标用户
- 建筑设计师、工程师
- 需要快速将扫描图纸数字化的专业人士
- 个人用户（DIY 项目）

### 1.4 核心价值
- 降低手工描绘线条的工作量
- 快速将模拟图纸转换为数字格式
- 生成的 DWG 可在 CAD 软件中进一步编辑

---

## 2. 功能需求

### 2.1 核心功能（MVP）

#### 2.1.1 文件上传
- 支持格式：PDF、PNG、JPG、JPEG
- 单个文件大小限制：≤ 200MB
- 支持单文件上传（暂不支持批量）

#### 2.1.2 图片处理
- 自动转化图片中的线条和轮廓
- 支持用户调整边缘检测参数（阈值、灵敏度等）
- 局部实时预览处理效果

#### 2.1.3 DWG 生成
- 将轮廓转换为 DWG 中的 polyline 对象
- 保留线条的连接关系和几何特性
- 支持版本范围 2004～2018，版本可选择
- 输出标准 DWG 格式

#### 2.1.4 文件下载
- 生成的 DWG 文件可直接下载
- 文件命名规则：时间戳 + 原文件名

### 2.2 扩展功能（后续迭代）

- 支持批量转换
- 支持 DXF 格式输出
- 支持图层管理（按颜色/类型分层）
- 支持在线预览 DWG 文件
- 用户账户系统（保存转换历史）

---

## 3. 非功能需求

### 3.1 性能
- 单个文件处理时间：< 30 秒（≤ 10MB）
- 系统响应时间：< 2 秒
- 并发用户数：≥ 10（初期）

### 3.2 可用性
- 界面简洁直观，无需复杂培训
- 支持拖拽上传
- 实时反馈处理进度

### 3.3 兼容性
- 浏览器：Chrome、Firefox、Safari（最新两个版本）
- 输出 DWG 兼容：CAD 版本 2004～2018

### 3.4 安全性
- 上传文件进行病毒扫描（可选）
- 用户上传的文件在处理后 24 小时内自动删除
- HTTPS 加密传输

## 4. 技术方案

### 4.1 技术栈

| 层级 | 技术 | 理由 |
|------|------|------|
| 后端 | Python + FastAPI | 开发快，OpenCV/ezdxf 生态完整 |
| 前端 | Vue 3 + Vite | 轻量级，开发体验好 |
| 图片处理 | OpenCV | 成熟的边缘检测和轮廓提取 |
| DWG 生成 | ezdxf | Python 原生 DWG 库 |
| 部署 | Cloudflare Workers | 无服务器架构，成本低，全球 CDN |
| 存储 | 内存处理 | 无需持久化存储，处理后自动释放 |

### 4.2 核心流程

```
用户上传 → 文件验证 → 图片预处理 → 边缘检测 → 轮廓提取 → 坐标转换 → DWG 生成 → 下载
```

### 4.3 内存管理策略

- 小文件（< 50MB）：直接内存处理
- 大文件（50-200MB）：流式处理或分块处理
- 处理完成后立即释放内存，无需磁盘存储

## 8. 风险与假设

### 8.1 风险
- 复杂图纸的线条提取效果可能不理想（需要参数调优）
- DWG 文件兼容性问题（不同 CAD 软件的支持度不同）

### 8.2 假设
- 用户上传的图片质量相对较好（清晰、对比度高）
- 初期用户量不大，不需要复杂的并发处理

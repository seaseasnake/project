# PDF to DWG 转换工具 - MVP 需求文档

## 1. MVP 范围

### 1.1 核心目标
用户上传图片 → 自动转化线条 → 生成 DWG 文件 → 下载

### 1.2 MVP 包含功能
- 文件上传（单个）
- 图片处理（自动转化）
- DWG 生成
- 文件下载

### 1.3 MVP 不包含功能
- 参数调整界面
- 实时预览
- 用户账户系统
- 批量转换
- 在线 DWG 预览

---

## 2. 功能详细需求

### 2.1 文件上传

**需求描述**
- 用户通过网页上传单个图片文件
- 支持格式：PDF、PNG、JPG、JPEG
- 文件大小限制：≤ 200MB

**交互流程**
1. 用户进入网页
2. 点击上传按钮或拖拽文件
3. 系统验证文件格式和大小
4. 验证通过后开始处理

**验证规则**
- 文件格式必须是 PDF、PNG、JPG、JPEG 之一
- 文件大小不超过 200MB
- 验证失败时显示错误提示

### 2.2 图片处理

**需求描述**
- 系统自动检测图片中的线条和轮廓
- 无需用户参数调整（MVP 阶段）
- 使用固定的边缘检测参数

**处理流程**
1. 如果是 PDF，转换为图片
2. 图片预处理（灰度化、降噪）
3. 边缘检测（Canny 算法）
4. 轮廓提取
5. 坐标转换为 DWG 坐标系

**技术细节**
- 使用 OpenCV 进行图片处理
- 边缘检测参数固定（不暴露给用户）
- 处理结果在内存中，不保存到磁盘

### 2.3 DWG 生成

**需求描述**
- 将提取的轮廓转换为 DWG polyline 对象
- 支持 DWG 版本：2004、2007、2010、2013、2018
- 默认输出 2018 版本

**生成规则**
- 每条轮廓生成一个 polyline
- 保留线条的连接关系
- 使用默认颜色（白色）和线宽

**技术细节**
- 使用 ezdxf 库生成 DWG 文件
- 坐标单位：毫米（mm）
- 文件在内存中生成，不保存到磁盘

### 2.4 文件下载

**需求描述**
- 用户可以直接下载生成的 DWG 文件
- 文件命名规则：时间戳 + 原文件名

**命名示例**
- 原文件：floor_plan.jpg
- 下载文件：20260318_190108_floor_plan.dwg

**交互流程**
1. 处理完成后显示下载按钮
2. 用户点击下载
3. 浏览器下载 DWG 文件

## 3. 用户界面需求

### 3.1 页面布局

**单页应用**
- 简洁的单页设计
- 上传区域 + 处理状态 + 下载按钮

### 3.2 上传区域
- 拖拽上传区域
- 点击选择文件按钮
- 显示已选文件名和大小

### 3.3 处理状态
- 显示处理进度（上传中、处理中、完成）
- 错误提示（格式错误、大小超限、处理失败）

### 3.4 下载区域
- 处理完成后显示下载按钮
- 显示生成的 DWG 文件信息（文件名、大小）

## 4. 技术架构

### 4.1 后端（FastAPI）

**主要端点**
```
POST /api/convert
- 接收上传的文件
- 返回处理状态和下载链接
```

**处理流程**
1. 接收文件
2. 验证文件格式和大小
3. 调用图片处理模块
4. 调用 DWG 生成模块
5. 返回下载链接

**错误处理**
- 文件格式错误 → 400 Bad Request
- 文件过大 → 413 Payload Too Large
- 处理失败 → 500 Internal Server Error

### 4.2 前端（Vue 3 + Vite）

**主要组件**
- UploadArea：文件上传区域
- ProcessStatus：处理状态显示
- DownloadButton：下载按钮

**状态管理**
- 文件信息（名称、大小、格式）
- 处理状态（idle、uploading、processing、completed、error）
- 错误信息

### 4.3 部署（Cloudflare Workers）

**部署方式**
- 后端部署到 Cloudflare Workers
- 前端部署到 Cloudflare Pages
- 使用 Cloudflare 的全球 CDN

**内存管理**
- 小文件（< 50MB）：直接内存处理
- 大文件（50-200MB）：流式处理
- 处理完成后立即释放内存

## 5. 非功能需求

### 5.1 性能
- 文件上传时间：< 10 秒（10MB 文件）
- 图片处理时间：< 20 秒（10MB 文件）
- 总处理时间：< 30 秒（10MB 文件）
- 系统响应时间：< 2 秒

### 5.2 可用性
- 界面简洁直观
- 支持拖拽上传
- 实时显示处理进度
- 清晰的错误提示

### 5.3 兼容性
- 浏览器：Chrome、Firefox、Safari（最新两个版本）
- 输出 DWG 兼容：CAD 版本 2004～2018

### 5.4 安全性
- HTTPS 加密传输
- 文件验证（格式、大小）
- 处理完成后立即释放内存（无磁盘存储）

## 8. 风险和假设

### 8.1 风险
- 复杂图纸的线条提取效果可能不理想
- DWG 文件兼容性问题（不同 CAD 软件的支持度不同）
- Cloudflare Workers 的内存限制可能影响大文件处理

### 8.2 假设
- 用户上传的图片质量相对较好（清晰、对比度高）
- 初期用户量不大，不需要复杂的并发处理
- 用户主要处理 < 50MB 的文件
